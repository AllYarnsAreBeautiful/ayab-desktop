# Pattern import fixtures

All fixtures in this directory are synthetic and generated by `generate.py`.
They contain only simple geometric pixel data created for these tests.

- `synthetic.pat` covers literal and repeated DesignaKnit PAT runs.
- `synthetic.stp` covers encrypted DesignaKnit STP blocks.
- `synthetic.cut` covers literal and repeated Dr. Halo CUT runs.

Run `python generate.py` from this directory to recreate all three files.
